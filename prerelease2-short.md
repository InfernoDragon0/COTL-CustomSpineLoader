**Cult Tweaker 2.0.0: World Shaper — Pre-release 2**

__Dungeon Builder__
- Improved the dungeon map into a full screen, with the game's own artwork
- Added free node placement, auto linking and drag to move
- Added Preview Map
- Added live checking of whether the map will play

__Level tool__
- Added hand-built floor layouts on a visual screen
- Added auto connecting doors
- Added fixed entrance and exit rooms
- Added a pool of maps per room, one is picked at random
- Added Combat and Reward room markers

__Room editor__
- Added move, resize and depth handles
- Added Ctrl-drag copying, for props and whole triggers
- Added a preview picture of the selection
- Improved terrain ordering into a list

__Editor panels__
- Improved the Load Map browser into a full screen, with a picture and details of each map
- Added search by name to the Structure, Enemy, NPC and Level tools
- Added a "Bosses (inside rooms)" list to the Enemy tool
- Added an unsaved changes prompt

__F7 panel__
- Added a player panel with a moving character preview
- Added saving of your chosen skin

__Fixes__
- Fixed an issue where a 2-room floor generated 4 rooms
- Fixed an issue where doors did not lock with monsters in the room
- Fixed an issue where a boss statue room replaced the weapon podium
- Fixed an issue where typing pressed the button under the mouse
- Fixed an issue where the Load Map browser stuttered

Full notes are in CHANGES.md. Back up your saves.
