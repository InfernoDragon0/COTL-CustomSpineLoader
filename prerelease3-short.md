**Cult Tweaker 2.0.0: World Shaper Pre-release 3**

__Base editor__

- Added base editor with F4 (must activate in F7 first)

__Hub building__

- Added capabilities to build a build totem for hubs (use this to allow vanilla building mechanics)
- Added build totem placement grid

__Main menu editor__

- Added a "Customize Menu" button on the title screen
- Added named presets for custom menus
- Added palette blend, background color and effect controls
- Added lamb skin, animation and placement, or custom spine
- Added logo replacement, edition text, color and position

__Editor UI__

- Improved all editors UI so that they use vanilla designs

__Weather__

- Added per-room weather to the Lighting tool, for dungeons and hubs
- Added custom strength weather

__Triggers__

- Added a variable Camera shake action

__Fixes__

- Fixed an issue where the room editor's status bar stopped working after using the world editor
