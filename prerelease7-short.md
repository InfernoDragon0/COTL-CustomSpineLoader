**Cult Tweaker 2.0.0: World Shaper Pre-release 7**

__Follower hats and clothes__

- Added custom hats and clothes for followers: via FollowerSpines packs
- Multi part clothes, meshes and weights supported, cross atlas
- Pick them per follower in Customize Follower
- Added a stripped follower rig for Spine: opens in seconds instead of minutes

__Brooms__

- Added broom transmog to the F7 panel
- Custom brooms via player spine configs, wearable by any spine

__Structure tool__

- Added favourites: right click to pin, star icon, Favourites group
- Added a 9 slot hotbar of pinned and recent things: 1-9 keys, mouse wheel
- Added boss and special room pieces
- Randomised sets now place as separate pieces
- Faster loading of maps with many structures

__Trigger tool__

- Added trigger methods: player step, blocking volume, enemy health threshold
- Added pause and resume enemy AI actions
- Targets can now point at an exact object

__For mod authors__

- Added world map progress to the API: complete, uncomplete, locks, keys
- Added FollowerHats and FollowerClothes to the API

__Fixes__

- Fixed an error when cleaning poop placed by the Structure tool
- Drag handles are now hollow rings and no longer hide what you drag
- Custom structures show their name instead of the registry key
