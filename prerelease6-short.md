**Cult Tweaker 2.0.0: World Shaper Pre-release 6**

__Custom weapons__

- Added custom weapons: via player spine configs
- Set animation, damage, speed, range, hitbox size, knockback and hit timing of each hit
- Cross spine compatibility with weapons
- Custom Chain weapons: sweep shapes, hook patterns, two chains per swing
- Added a Debug / WeaponHitboxes setting that draws every hit shape, and Podium tool dropdown to pick the weapon

__Custom NPC quests__

- Added quests to custom NPCs
- Criterias: gather, kill, build, recruit, clear dungeon, ritual, etc
- Added rewards, repeatable quests and expiry timers;

__Whiteboard__

- Added a Whiteboard tool: draw and erase planning marks over the room, 9 colors, sizes, undo per stroke, clear all
- Hides when the editor closes, saved with the map

__For mod authors__

- Added a code contract so other mods can find and use what CultTweaker loaded

__Fixes__

- Fixed door pads growing across the room and into a central hole
- Fixed the guest stuck on the summoning screen when the host enters a custom dungeon level
- Fixed enemy bodies left behind on the guest after a move from the other player
