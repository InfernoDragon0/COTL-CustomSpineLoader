# Cult Tweaker 2.0.0: World Shaper, Pre-release 2

Everything new since pre-release 1.

## Dungeon Builder

- Improved the dungeon map into a full screen
- Improved the map to use the game's own artwork
- Added free node placement
- Added `Ctrl+click` to place, right-click to link or cut, `Del` to delete
- Added auto linking when you place beside a selected node
- Improved dragging so links follow the node
- Improved linking so any node can lead to any other
- Added **Preview Map**
- Added live checking of whether the map will play
- Improved compatibility with maps saved in pre-release 1
- Improved closing with `Esc`, the X button or `F4`

## Level tool

- Added hand-built floor layouts ("custom walk")
- Added a visual layout screen
- Added auto connecting doors
- Added a random walk tickbox
- Added fixed entrance and exit rooms
- Added a choice of vanilla podium entrance and exit rooms
- Added a pool of maps per room, one is picked at random
- Added Combat and Reward room markers
- Added right-click to turn a room's doors on and off
- Improved the door labels to Up / Down / Left / Right
- Removed the Done button, the second menu, Rename Level and Delete Room
- Fixed an issue where a 2-room floor generated 4 rooms

## Room editor

- Added move, resize and depth handles
- Added `Ctrl`-drag copying
- Added a preview picture of the selection
- Added right-click to deselect
- Improved flip into a tickbox
- Improved terrain ordering into a list with `-` and `+`
- Added `Ctrl`-drag copying of whole triggers
- Added colours to trigger boxes
- Improved *Clear All Triggers* into the Clear tool
- Improved long trigger lists to scroll
- Fixed an issue where older rooms had their terrain order changed

## Editor panels

- Added an unsaved changes prompt
- Added search by name to the Structure, Enemy, NPC and Level tools
- Added a "Bosses (inside rooms)" list to the Enemy tool
- Added a bigger preview when you hover an icon
- Improved the icon lists to scroll on their own
- Improved the scrollbars into a thin rail
- Improved the Load Map browser into a full screen
- Added a picture and details of the map you pick
- Added click to enlarge the picture
- Improved the Lighting tool to capture the room's lighting on open
- Fixed an issue where typing pressed the button under the mouse
- Fixed an issue where the game's menus stole the keyboard while naming
- Fixed an issue where *Reset To Biome* left the sliders where they were
- Fixed an issue where the Load Map browser stuttered
- Fixed an issue where picking a room in the Level tool paused each time
- Fixed an issue where map pictures looked blurry in game
- Fixed an issue where character previews stopped drawing after a game update

## Door tool

- Improved the floor padding beside doors to be invisible but walkable

## F7 CultTweaker panel

- Added a player panel in the bottom-left corner
- Added a moving character preview
- Added a preview animation dropdown
- Added saving of your chosen skin
- Improved fleece transmog to be per player
- Improved the layout into **Go** and **Extras** sections
- Improved the text sizes to match the editor

## Custom dungeons

- Fixed an issue where doors did not lock with monsters in the room
- Fixed an issue where a boss statue room replaced the weapon podium
